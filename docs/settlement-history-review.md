## iPhone Preview에서 확인할 항목

- [ ] 홈 화면 `정산 기록 보기`와 바로 아래 `총 금액` 카드 외곽선 사이에 다른 주요 블록과 동일한 세로 간격이 보입니다.
- [ ] 진행 중인 정산이 있으면 `정산 기록` 화면 상단에 `진행 중인 정산`으로 계속 보입니다.
- [ ] 미정산 슬롯이 남아 있는 동안 `새 정산`을 눌러도 현재 정산을 지우지 않고 미정산 결제로 이동합니다.
- [ ] 만료된 결제 요청은 `새 결제 요청 만들기`로 재발급할 수 있고, 새 QR을 다시 공유할 수 있습니다.
- [ ] 재발급 이후에도 기존 결제 요청이 늦게 결제되면 기존 정산 화면 또는 완료 기록에서 중복 입금 가능성을 확인할 수 있습니다.
- [ ] 모든 결제가 확인된 뒤 `새 정산`을 누르면 완료 정산이 장기 기록으로 이동합니다.
- [ ] 장기 기록 상세 화면에서 과거 QR이나 BOLT11을 다시 결제·공유하는 기능이 노출되지 않습니다.
- [ ] QR 공유 시 iOS 공유 시트에 QR PNG와 결제 요청 텍스트가 함께 전달됩니다.
- [ ] QR 파일 공유가 불가능한 환경에서는 텍스트 공유 또는 클립보드 복사 fallback이 동작합니다.
- [ ] 원화·달러·sats 정산 기록의 금액 단위가 명확하며 달러는 `$` 기호를 표시합니다.
- [ ] 한국어/영어 전환 후 정산 기록과 공유 문구가 해당 언어로 표시됩니다.
- [ ] Safari 새로고침/PWA 재실행 후 진행 중 정산과 완료 기록이 복구됩니다.

## 안전성 확인

- [ ] 진행 중 정산을 `정산 중단·삭제`할 때 늦은 결제를 더 이상 추적하지 못할 수 있다는 강한 경고가 표시됩니다.
- [ ] 완료 기록 삭제는 실제 Lightning 결제에 영향을 주지 않는다는 설명이 표시됩니다.
- [ ] 완료 기록의 IndexedDB 표시 데이터에 Lightning Address, BOLT11, payment hash, verification token, provider domain이 포함되지 않습니다.
- [ ] 완료 후 임시 추적 정보는 해당 invoice 만료 + 보존 기간이 지나면 삭제됩니다.

실기기 검증이 끝날 때까지 `main`으로 merge하거나 production 배포하지 않습니다.
